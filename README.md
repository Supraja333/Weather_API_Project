City Weather Search is a lightweight full-stack application that allows users to look up current weather information for any city in the world. The project is built with: FastAPI (Python) — backend proxy service OpenWeather Current Weather API — external weather provider HTML/CSS/JavaScript — frontend UI Local in-memory caching — improves performance and reduces API calls The application runs fully locally, requires only Python 3.9+, and works with any valid OpenWeather API key.
